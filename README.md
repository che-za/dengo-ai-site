# Сайт Dengo AI

Статический сайт без сборки: две страницы, общий стиль и маленький скрипт.
Внешних запросов нет: шрифты системные, ни cookie, ни аналитики, ни YouTube.

```
index.html          литовская версия (основная)
ru/index.html       русская версия
assets/style.css    оформление
assets/main.js      анимация чата на первом экране
assets/favicon.svg  значок
.nojekyll           нужен для GitHub Pages, не удалять
```

Посмотреть у себя: распакуйте архив и откройте `index.html` в браузере.

## Тексты

Тексты правятся прямо в `index.html` и `ru/index.html`, структура у файлов одинаковая.
Реплики в чате на первом экране выдуманы; их можно заменить настоящими ответами бота.

## Цифры о часах работы

Блок в разделе «Проблема»: 20 автосервисов (10 Вильнюса, 10 Каунаса) по Google Maps,
4 работают после 18:00, 3 — по субботам, 0 — по воскресеньям. Список сервисов с часами хранится у вас.
Если пересчитаете, поменяйте цифры в обоих файлах (блок `<div class="stat">`).

## Анкета Google Forms

В блоке «Ieškome pirmųjų autoservisų» есть кнопка «Užpildyti anketą».
Когда создадите форму, замените в обоих файлах `https://forms.gle/` на её ссылку
(рядом стоит комментарий «PAKEISKITE»). До этого кнопка ведёт на пустую страницу Google.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Add file → Upload files: перетащите всё содержимое папки (включая `.nojekyll`).
3. Settings → Pages → Build and deployment: Source «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту сайт откроется по адресу `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`.

Свой домен dengo-ai.lt подключается позже в том же разделе (Custom domain) плюс записи DNS.

## Чего не добавлять без правки подвала

Google Fonts, Google Analytics, пиксели, YouTube-плееры и формы. Иначе строка
«Svetainė nenaudoja slapukų» станет неправдой и понадобится политика конфиденциальности.
